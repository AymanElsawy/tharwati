# Follow-up work

## Liabilities & Credit Accounts

Deferred from the non-liability account workflow. This work requires explicit
liability-capable account types, an account `balance_nature` (or equivalent)
classification, `credit_limit`, a spending/cash-statistics exclusion preference,
Net Worth liability integration, a forward-only database migration, and database
and application regression tests. Existing accounts must not be silently
reclassified when this work is implemented.
