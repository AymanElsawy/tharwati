# Data Model

## Core Entities

The application is built around a small number of core entities.

Every feature in Tharwati should be connected to one or more of these entities.

---

## User

Represents the account owner.

---

## Financial Profile

Represents the user's complete financial life.

---

## Asset

Represents anything the user owns.

Examples:

- Cash
- Investment
- Gold
- Property
- Business

---

## Liability

Represents anything the user owes.

---

## Goal

Represents a financial objective.

---

## Transaction

Represents any financial movement that changes an asset or liability.

---

## Insight

Represents information generated by the system.

---

## AI Recommendation

Represents personalized recommendations generated from the user's financial profile.
---
